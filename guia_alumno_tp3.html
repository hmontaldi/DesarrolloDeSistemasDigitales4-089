Guía para el Alumno

TP N°3 — Etapa 4: Desarrollo del Software · Desarrollo de Sistemas Digitales · 5° Año · Prof. Humberto Montaldi · 2026

Esta guía te acompaña en la construcción de la página HTML/CSS/JS de tu sistema, a partir del prototipo que ya diseñaste en el TP N°2. También te muestra cómo pedirle ayuda a una IA sin perder el control de lo que estás entregando: recordá que en la puesta en común vas a tener que explicar cada línea de tu código.

1. Antes de empezar: recuperá tu diseño 20 pts

Abrí el TP N°2 y tené a mano el prototipo aprobado. No arranques a programar sin esto: es la base de todo lo que sigue.

  • Hacé una lista de las pantallas o secciones que va a tener tu página.
  • Para cada una, anotá qué datos muestra o qué datos pide al usuario.
  • Si tenés bocetos o capturas del TP N°2, guardalos cerca: se los vas a describir a la IA en el paso 3.

2. Estructura y estilo — HTML + CSS 40 pts

Construí primero el esqueleto HTML de cada pantalla que listaste, respetando el orden y los contenidos del prototipo. Después sumá el CSS: colores, tipografía y distribución coherentes con lo que diseñaste. El resultado debe verse ordenado y legible.

  • Un archivo HTML por pantalla, o todo en un único .html con secciones bien separadas.
  • Usá etiquetas semánticas (header, main, section, footer) en vez de puros <div>.
  • Revisá que el texto se lea bien y que los botones/campos tengan tamaño cómodo para tocar o clickear.

3. Funcionalidad — JavaScript 28 pts

Sumá al menos una funcionalidad interactiva real: validar un dato, mostrar/ocultar información, guardar algo, buscar algo. Elegí una que tenga sentido con el requisito funcional de tu sistema, no una genérica.

4. Documentar el código 12 pts

Agregá comentarios breves arriba de cada bloque importante de HTML, CSS y JS explicando qué hace. No hace falta comentar línea por línea: alcanza con explicar el "para qué" de cada parte.

Cómo usar la IA como apoyo (sin perder el control)

Podés usar una IA (Claude, ChatGPT, Gemini, etc.) para generar o corregir código. La regla es una sola: tenés que poder explicar cada línea que entregás. Para que la IA te ayude bien, no le pidas "hacé la página" a secas — describile tu diseño del TP N°2. Copiá y completá esta plantilla:

Estoy haciendo el TP N°3 de Desarrollo de Sistemas Digitales (Etapa 4: Desarrollo). Ya tengo un prototipo aprobado del TP N°2. Quiero que me ayudes a programarlo en HTML, CSS y JavaScript (todo en un solo archivo .html), explicándome cada parte para poder defenderlo en clase. Mi sistema es: [nombre y breve descripción del sistema]. Pantallas o secciones que necesito (según mi TP N°2): 1. [nombre de la pantalla] – muestra/pide: [datos] 2. [nombre de la pantalla] – muestra/pide: [datos] 3. [agregar las que falten] Estilo visual que quiero (colores, tipografía, distribución, según mi prototipo): [describir o pegar referencia del boceto] Funcionalidad interactiva que necesito programar en JavaScript: [ej: validar que un campo no esté vacío / mostrar-ocultar un panel / guardar datos en una lista / buscar un elemento en la lista] Por favor: - Generá el HTML, CSS y JS juntos en un solo archivo. - Agregá comentarios breves arriba de cada bloque explicando qué hace. - Usá código simple, sin librerías externas, para que lo pueda explicar en clase. - Al final, hacéme un resumen en lenguaje simple de qué hace cada parte del código.

Después de que la IA te dé el código: leelo entero, pedile que te explique cualquier línea que no entiendas, y probalo en el navegador antes de entregar. Si algo no anda, describile el error a la IA (o pegá el mensaje de la consola) para corregirlo junto con ella.
